# Attribution, correction, and removal requests

ImgLume respects original authors and preserves the source author and X post
URL for every record.

If you are an original author or authorized representative, open a
[removal request](https://github.com/Hanyuyu/imglume-prompts/issues/new?template=removal-request.yml)
for:

- removal of a prompt or source-media link;
- correction of author attribution;
- correction of a source URL;
- a licensing notice supported by the rights holder.

Please include the dataset record ID, source post URL, the requested action,
and a way to verify your relationship to the source account. Do not publish
private identity documents or sensitive personal information in an issue.

ImgLume will review the source record, make the appropriate upstream change,
and let the automated synchronization update this repository. A removal from
the current snapshot does not rewrite Git history, so requests that require
history removal will be evaluated separately.
